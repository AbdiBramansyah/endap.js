Pendulum: small-angle approximation vs numerical solution

The small-angle solution is θthe(t) = A cos(ω0t) with ω0 = √(g/R). The numerical solution integrates θ″ = −(g/R) sin θ using semi-implicit Euler. The amplitude is A = aπ, for a = 0.1, 0.2, …, 0.9, 0.99.

For small a the two curves nearly coincide. As a increases, the nonlinear period becomes longer than T0 = 2π/ω0, so the numerical curve gradually drifts out of phase with the small-angle solution.
